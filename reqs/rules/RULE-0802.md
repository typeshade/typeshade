**Rule 8.2.** A vertex entry must return the position, as a bare `vec4` or as a struct with a `builtin<"position", vec4>` field; a fragment entry returns one `location<0, T>` value, a struct of render targets, or nothing. The decorated field, `@builtin("position")`, stays accepted until the release after the migration release (change 0111, D5).

- Rationale: nothing can invent a position, and WGSL says so.
- Derives from: [Restrictions on Functions](https://gpuweb.github.io/gpuweb/wgsl/#function-restriction) ("a vertex shader must return the position built-in output value"); change `0111` in `changes/` (D2); surface §3.
- Enforced by: `src/compiler/ts/entry-io.test.ts`; `src/compiler/ts/attribute-types.test.ts` for the position written as a type.
