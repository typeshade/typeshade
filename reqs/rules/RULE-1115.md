**Rule 11.15.** A test must fail when a member of a source has no row, and when a row names a member that no source has. The sources are pinned by version, and a version bump re-bakes the table as a reviewed diff (Rule 11.4 applies: a re-bake is read, not rubber-stamped).

- Rationale: a table nothing holds to its sources drifts the day a package updates; the API surface already works this way (`src/__api__/surface.md`, Rule 11.6).
- Derives from: Rule 11.6; `scripts/bake-wgsl-names.ts` and `surface-names.test.ts`, which hold the WGSL names to the specification the same way.
- Enforced by: `capability-coverage.test.ts`, which reads the four sources at their pinned versions and the classification, and fails on an unclaimed member and on a stray row.
