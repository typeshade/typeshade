**Rule 6.7.** The attribute names the compiler reads are `vertex`, `fragment`, `compute`, `workgroup_size`, `builtin`, `location`, `interpolate`, `invariant` and `blend_src` (the last three since #168, surface §53), and GLSL's qualifiers `inout` and `out` on a parameter of a function of the file (Rule 8.25, change 0040). A stage is an attribute on the entry's function declaration (`@vertex`, `@fragment`, `@compute([x, y?, z?])`, Rule 8.1), and a kernel's size the optional attribute `@workgroup_size([n])` (Rule 8.22); `builtin` and `location` are types and `interpolate`, `invariant` and `blend_src` their options (Rule 6.6), and `inout` and `out` are attributes written before a parameter, `@inout a: f32` and `@out c: f32` (Rule 8.25, change 0137). Change 0131 removed `numerics`, and a leftover `numerics(...)` is an unknown function (`TS8004`); change 0132 removed `diagnostic`, whose work the compiler's rewrite does (Rule 8.5), and a leftover `@diagnostic(…)` decorator is `TS8028`, which says to delete it; an option written on a stage call is named in the refusal of the call.
Every other WGSL attribute is inferred by the compiler.
The calls `vertex(f)`, `fragment(f)`, `compute([…], f)` and `workgroup_size([…], f)` must be refused with `TS8028`, whose text names the attribute and `tshc migrate` (change 0130, D4, as amended by change 0140); the decorators `@builtin`, `@location`, `@interpolate`, `@invariant` and `@blend_src` on a parameter or a field stay as change 0111 D5 says; a decorator outside the list must be refused.

- Rationale: a misspelled attribute or stage name would otherwise silently stop a function being an entry point. The attributes keep WGSL's names (change 0100, change 0111 Amendment 1); a stage marks a function, so it is an attribute on the function's declaration, and an input or an output is a value, so its attribute is part of its type (Rule 1.8); a parameter qualifier is written before the parameter, as GLSL writes it (OD-5).
- Derives from: [Attributes](https://gpuweb.github.io/gpuweb/wgsl/#attributes); the fixture's `attributes` list against the ambient library; change `0111` in `changes/`; change `0130`; change `0137`; change `0140`.
