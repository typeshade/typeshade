**Rule 6.7.** The attribute names the compiler reads are `vertex`, `fragment`, `compute`, `workgroup_size`, `builtin`, `location`, `interpolate`, `invariant` and `blend_src` (the last three since #168, surface §53), and GLSL's qualifiers `inout` and `out` on a parameter of a function of the file (Rule 8.25, change 0040). Each is written where a plain `tsc --strict` accepts it (change 0111): a stage is a call that wraps the entry's function (`vertex(f)`, `fragment(f)`, `compute([64, 1, 1], f)`, Rule 8.1), `builtin` and `location` are types and `interpolate`, `invariant` and `blend_src` their options (Rule 6.6), and `inout` and `out` are the types `inout<T>` and `out<T>` (Rule 8.25, D4). A stage call takes no options: change 0131 removed `numerics`, and a leftover `numerics(...)` is an unknown function (`TS8004`); change 0132 removed `diagnostic`, whose work the compiler's rewrite does (Rule 8.5), and a leftover `{ diagnostic: [...] }` option or `@diagnostic(…)` decorator is `TS8028`, which says to delete it.
Every other WGSL attribute is either inferred by the compiler or carried as an argument (`compute([64, 1, 1], f)` carries `@workgroup_size`, and so does `workgroup_size([128], f)` on a kernel function, Rule 8.22).
The decorated forms, `@vertex`, `@fragment`, `@compute([…])`, `@workgroup_size([…])` on a function and `@builtin`, `@location`, `@interpolate`, `@invariant`, `@blend_src`, `@inout` and `@out` on a parameter or a field, are accepted in the migration release with a `TS8028` warning on each decorator that names its new form and `tshc migrate`, and are refused in the release after it (change 0111, Amendment 2, D5); a decorator outside that list must be refused, `@workgroup_size` on any other function included.

- Rationale: a misspelled decorator or stage name would otherwise silently stop a function being an entry point. The attributes keep WGSL's names (change 0100, change 0111 Amendment 1) and change only where they are written, since a plain TypeScript compiler refuses a decorator on a function declaration or on its parameter (TS1206).
