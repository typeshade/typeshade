**Rule 6.7.** The attribute names the compiler reads are `vertex`, `fragment`, `compute`, `workgroup_size`, `builtin`, `location`, `interpolate`, `invariant`, `blend_src` and `diagnostic` (the last four since #168, surface §53 and §54), GLSL's qualifiers `inout` and `out` on a parameter of a function of the file (Rule 8.25, change 0040), and `numerics`, a function's numerical contract (Rule 11.22, change 0107). Each is written where a plain `tsc --strict` accepts it (change 0111): a stage is a call that wraps the entry's function (`vertex(f)`, `fragment(f)`, `compute([64, 1, 1], f)`, Rule 8.1), `diagnostic` is that call's options argument (`fragment(f, { diagnostic: ["off", "derivative_uniformity"] })`, D7), `builtin` and `location` are types and `interpolate`, `invariant` and `blend_src` their options (Rule 6.6), `inout` and `out` are the types `inout<T>` and `out<T>` (Rule 8.25, D4), and `numerics` is a call that wraps a function of the file, `const f = numerics(["finite-math"], function f(…) { … })`, or a stage call's option, `{ numerics: ["finite-math"] }`; a wrong class list, and the call written anywhere else, is `TS8078`.
Every other WGSL attribute is either inferred by the compiler or carried as an argument (`compute([64, 1, 1], f)` carries `@workgroup_size`, and so does `workgroup_size([128], f)` on a kernel function, Rule 8.22).
The decorated forms, `@vertex`, `@fragment`, `@compute([…])`, `@workgroup_size([…])`, `@diagnostic(…)` on a function and `@builtin`, `@location`, `@interpolate`, `@invariant`, `@blend_src`, `@inout` and `@out` on a parameter or a field, stay accepted until the release after the migration release (change 0111, Amendment 2, D5); a decorator outside that list must be refused, `@workgroup_size` on any other function included.

- Rationale: a misspelled decorator or stage name would otherwise silently stop a function being an entry point. The attributes keep WGSL's names (change 0100, change 0111 Amendment 1) and change only where they are written, since a plain TypeScript compiler refuses a decorator on a function declaration or on its parameter (TS1206).
- Derives from: [Attributes](https://gpuweb.github.io/gpuweb/wgsl/#attributes); the fixture's `attributes` list against the ambient library; change `0111` in `changes/`.
