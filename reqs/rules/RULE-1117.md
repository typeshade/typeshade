**Rule 11.17.** A `raw` row must name one documented escape hatch, and the escape hatches are exactly these: `Frame.encoder`, `RenderPass.raw`, `Texture.texture`, `Sampler.sampler`, `Runtime.device`, `createRuntime({ device })`, a host `GPUBuffer`, `GPUTexture`, `GPUTextureView`, `GPUSampler`, `WebGLBuffer`, `WebGLTexture` or `WebGLSampler` passed as a binding, a target or a geometry buffer, `RenderPipeline.draw(pass, …)` and `ComputePipeline.dispatch(target, …)` into the host's own encoders, and `Runtime.submit(…encoders)`. Each is documented in its JSDoc as an escape hatch. Removing one, or narrowing what it accepts, is a breaking change (Rule 13.9).

- Rationale: an escape hatch is the promise that a capability the runtime does not spell is still reachable without leaving the runtime; a host builds on it, so it is part of the public surface and not a convenience that may go.
- Derives from: Rule 11.11; `src/runtime/runtime.ts` (`Frame.encoder`, `RenderPass.raw`, `Runtime.device`), `src/runtime/resources.ts` (`Texture.texture`, `Sampler.sampler`), `src/runtime/program.ts` (the host objects a binding and a `Geometry` take); Rule 13.9.
- Enforced by: `capability-coverage.test.ts`, which fails on a `raw` row that names nothing in the list, and `src/api-surface.test.ts`, which already fails on a removed export.
