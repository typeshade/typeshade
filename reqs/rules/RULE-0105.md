**Rule 1.5.** The representation of a form ECMAScript defines is the compiler's: a value on the stack, a binding, or memory the compiler owns, and it may change between versions while every observable answer stays the one Rule 1.1 defines.
A program whose form the compiler cannot represent on a target is refused there in one sentence naming the reason, or, for a call the CPU tier can run, runs there and says why (Rule 11.7).

- Rationale: the meaning is the language's and the representation is the compiler's, as change 0080 (its section 1) stated for `Map` and `Set`. What memory the compiler owns, how it is sized and how it appears to the host are unit S3 of `docs/typeshade-plan.md`, not this rule.
- Derives from: `changes/0100-typescript-meaning.md` (section 2); `changes/0080-kernel-map-set.md`.
- Enforced by: review, which reads a refusal against Rule 4.5 and a call the CPU tier runs against Rule 11.7; Appendix B, under Rule 1.1, for the memory the compiler does not yet own.
