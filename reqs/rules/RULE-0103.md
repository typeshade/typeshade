**Rule 1.3.** The CPU oracle is the reference evaluation of the meaning this document defines (Rule 1.1): ECMAScript's result for a form borrowed from ECMAScript, with the arithmetic of the WGSL types the program uses, WGSL's result for a form borrowed from WGSL, the recorded result where a rule gives another, and, where WGSL leaves room (§11), one of the permitted answers.

- Rationale: a test that compares a GPU result with the oracle is only meaningful if the oracle is the specification's answer and not a third opinion. The CPU tier of change 0080 already uses JavaScript's own `Map` and `Set` as the oracle.
- Derives from: `changes/0100-typescript-meaning.md` (section 2); [Floating Point Evaluation](https://gpuweb.github.io/gpuweb/wgsl/#floating-point-evaluation) and `AGENTS.md` ("one IR, three backends").
- Enforced by: `src/core/oracle-backend-parity.test.ts` and `src/core/passes/determinism.test.ts`.
