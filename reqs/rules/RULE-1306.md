**Rule 13.6.** A new author-facing name must be added only by its source: a WGSL name by citing the specification section that declares it, and an ECMAScript name by citing the section of ECMA-262, or the declaration of TypeScript's standard library, that defines it.
A TypeShade extension, including a new type of the f64 family, must be added by Rule 9.7, with the rationale in §9 and, for the f64 family, in Rule 4.4.

- Rationale: see Rule 2.1.
- Derives from: the comment above `TYPESHADE_EXTENSIONS` in `surface-names.test.ts`, which names §9 and this section; `changes/0100-typescript-meaning.md` (section 2) for the ECMAScript citation.
- Enforced by: `surface-names.test.ts`, which accepts an ECMAScript name from `Math`, `console`, `Array.prototype`, `Map` and `Set`; the test is narrower than the rule and grows with each unit of `docs/typeshade-plan.md` that adds a name.
