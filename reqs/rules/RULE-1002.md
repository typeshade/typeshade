**Rule 10.2.** The compiler must derive `requiredFeatures` from the module and must report them through `reflect()`, with every implied capability included. A feature that only a variant of a compute entry needs (Rule 11.23) is not among them: the runtime requests it where the adapter has it, and never requires it.

- Rationale: a host activates features off `reflect()`, so the list must be the whole set and not the half the author named.
- Derives from: `requiredCaps` and `CAP_IMPLIES` in `src/core/passes/required-caps.ts`. Change `0119` (the variant's feature).
- Enforced by: `src/core/backends/extension-profile.test.ts` and `required-caps.test.ts`; `requestCallDevice` in `src/core/host-entry.ts` (`SUBGROUPS`, requested as `timestamp-query` is), pinned by `src/runtime/device.test.ts`.
