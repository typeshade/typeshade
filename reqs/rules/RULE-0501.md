**Rule 5.1.** An integer-written literal must take the integer type the position around it declares. An unannotated function-local `let` initialized by such a literal takes `i32` or `u32` when declared uses require that one type for the local: direct calls to declared, nongeneric functions, constructor and instance or static method arguments, and explicitly typed initialization or simple assignment. A simple assignment can take the type of its destination or of a right-hand side that declares its type independently of the local. Resolve the local, callee and receiver by their declarations, including through nested scopes and inherited members; an override supplies its own signature. A concrete member parameter independent of generic arguments can establish a demand; an unresolved generic parameter or circular inference cannot. Conflicting concrete scalar types must be refused with an annotation or cast remedy. Where no integer type is established, the literal must be an `f32`. An unannotated `const` whose initializer is written numbers, and `+`, `-`, `*` and `/` over written numbers and such constants, must be a constant of no fixed type: at module scope, in a function, or as a static field that no code writes. Its value is the ECMAScript value of the initializer. Each read of it must take the type that the written number would take in the same place, and a conversion (`u32(K)`) must convert the written number. A read that takes `f32` names the emitted `f32` declaration, and a read of another type writes the value. A `/` whose operands have no declared type and reach such a constant, directly or through `+`, `-`, `*`, `%`, a bitwise operator, a builtin, a conditional, a constant derived from it or a variable with no annotation that is initialized from it, must be refused where another read makes that constant an integer, a conversion to `i32` or `u32` and a read in a file that imports it included. The quotient's own read is not another read: `let j: u32 = K / 2` is `4u` with `const K = 8`, as the written `8 / 2` is. The refusal must name one edit that compiles where the quotient stands.

- Rationale: this is WGSL's abstract-integer rule narrowed to the positions where a type is stated, and the `f32` default is the surface's history rather than WGSL's rule.
- Derives from: [Abstract Numeric Types](https://gpuweb.github.io/gpuweb/wgsl/#abstract-types) and [Conversion Rank](https://gpuweb.github.io/gpuweb/wgsl/#conversion-rank); surface §13.
