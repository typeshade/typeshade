**Rule 8.23.** A kernel function's parameter of an array with no size is the caller's storage, passed by reference: the body reads and writes its elements in place, reads its `.length`, and cannot assign it whole; whether the body writes it decides its access. The `.length` of such an array counts elements, so an `array<vec4f>` counts vectors (change 0068).
A kernel function's texture parameter (change 0077), a `texture_2d<f32>` or a 2D storage texture, is the caller's texture, passed by reference the same way: the body loads it with `textureLoad`, measures it with `textureDimensions`, stores into a storage texture with `textureStore`, and cannot assign it whole.
An array parameter a loop pushes onto (change 0078) starts empty in the function: the pushes append in the order a sequential run of the loop makes them, iteration by iteration and statement by statement, on every tier, and its `.length` is the count appended, which may exceed the host array's length. The host array is the capacity: the call writes elements `0` to `min(count, capacity) - 1` and leaves the rest as they were, and the host reads the count through the function's own `return out.length`.
A kernel function is emitted by no target, since it runs on the host's side of the call; an `array<T, N>` parameter stays by value.

- Rationale: `render(k, 512, img)` fills `img`, which is TypeScript's own meaning of a typed-array argument, and a runtime-sized array exists only in storage (Rule 12.6), so a copy has no meaning.
- Derives from: change `0013` in `changes/`; Rule 8.8; Rule 12.6.
- Enforced by: `parseParams` and `fillFunctionBody` in `src/compiler/ts/lower/function.ts`, which take the parameter as an `inout` storage array for a kernel function and refuse it on any other (`TS8020`); `withoutKernels` in `src/core/ir/kernels.ts`, which every backend and `reflect()` read through; pinned by `src/compiler/ts/kernel-loops.test.ts`, which runs a kernel function on the CPU oracle and holds the caller's array written in place. A texture parameter is a handle binding of the loop's entry (`lowerKernel` in `src/core/passes/kernel-lower.ts`) and a `texture` parameter of the face (`kernelFace` in `src/compiler/ts/host-face.ts`); pinned by `src/compiler/ts/host-kernel-texture.test.ts` and by the import journey, whose `invertImage` stores into a device's texture on WebGPU in Chromium, each byte the reference's. A pushed array's count is `pushedParams` and `countPushedLengths` in `src/compiler/ts/lower/kernel-push.ts` and the builtins `push` and `pushCount` of `src/core/cpu-runtime.ts`; pinned by `src/compiler/ts/host-kernel-push.test.ts` on the CPU tier: the order, an empty result, a count past the capacity, two pushes in one iteration and a second call that starts empty.
