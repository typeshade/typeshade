**Rule 11.10.** A compiled program's manifest, what `packModule()` returns and what the default export of a module's host import is, must be one JSON object that carries its schema (`schema`, 1) and the package version that wrote it (`compiler`); each binding with its group and slot, its resource in `reflect()`'s vocabulary, the stages that reach it, and a buffer's byte layout with every offset, size and stride under the rule of its space (Rule 6.8), the `_fp64` guard the emit adds among them; each entry with its stage, its workgroup size, its inputs and outputs with their locations, builtins and interpolation, the bindings it reaches and which it writes, a vertex entry's vertex buffer, and its line; the overrides and the WebGPU features; with `console`, the recorded variant, its WGSL, its log table and its bindings; what the WebGL2 tier uses, each full-screen fragment entry's GLSL ES 3.00 program, block names and texture-sampler pairs, and each storage array's data texture; and with `ir`, the program's portable IR, which records the package version that wrote it (Rule 11.11).
It is built from the IR alone, with no TypeScript, so every producer builds the same one; a reader must refuse a schema it does not know, naming both.

- Rationale: a host that runs a program needed `reflect()` for its offsets, parsed type strings for its resources, and re-derived what the call layer computed privately; a stored program with no version cannot say which runtime reads it, which an engine's shader cache needs.
- Derives from: change `0025` in `changes/` (section 1); issue #335 (principle 4); Rule 6.8.
- Enforced by: `buildManifest` in `src/core/manifest.ts`, which `packModule` in `src/compiler/ts/pack.ts` and `hostFace` in `src/compiler/ts/host-face.ts` call; pinned by `src/core/manifest.test.ts`, over every example (schema, version, JSON round trip, slots, entries, offsets, vertex layout, the recorded variant, a data texture's format against the GLSL, the call layer's layouts), by `src/core/ir/portable.test.ts`, over every example, for `ir`, and by `src/vite.test.ts`, which imports a module's default export through the plugin and bundles it alone with no CPU tier, and adds the IR with `ir: true`.
