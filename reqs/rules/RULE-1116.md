**Rule 11.16.** A capability that only WebGL2 has must enter the surface only as a row of §9.3 (an author-facing name) or as a capability of §10 (a host feature a module declares or derives); it must not become a language construct, a built-in value or a type by another route. Where neither is justified, its row is `n/a` with the reason, and the reason is a rule.

- Rationale: Rule 1.2 makes GLSL ES 3.00 a target and not the definition of a construct, and Rule 2.1 gives an author-facing name three sources, none of which is WebGL2; a WebGL2-only capability therefore needs the one door the rules leave open, and a row that says `n/a` without a rule is the "TypeShade cannot" this proposal exists to end.
- Derives from: Rule 1.2; Rule 2.1; Rule 9.6; Rule 10.4.
- Enforced by: `capability-coverage.test.ts`, which fails on a WebGL2-flagged row whose WebGL2 status is `typed` with no §9.3 row and no §10 capability behind it, and on one whose status is `n/a` with no rule number in its reason.
