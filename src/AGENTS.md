# src

## Purpose

All source of the `typeshade` package. Two layers share one IR. The `"use typeshade"` front end
(`compiler/ts/`) lowers an ordinary TypeScript file into that IR; `core/` holds the IR, the
lower-level EDSL (`fn`, `Let` / `Var`, `If` / `Switch`, `.assign()`), the one neutral emit walk,
the WGSL and GLSL ES 3.00 writers, the CPU f64 oracle, the pass pipeline and the layout layer.
Concrete shaders live in `examples/` and in consuming projects, never here.

## Entry points

Every file below but the last is a `package.json` `exports` subpath, and every one of those but
`runtime-internal.ts` is public API: `API_SUBPATHS` in `api-subpaths.ts`, the one list that
`api-doc-coverage.test.ts` and `api-surface.test.ts` both read. `__api__/surface.md` lists every
symbol the API subpaths export; it is generated (`bun run bake:api-surface`) and
`api-surface.test.ts` fails when it and the tree disagree. `__api__/author-names.md` lists every
author-facing name the ambient library declares (docs/language-design.md §2.1); it is generated
(`bun run bake:author-names`) and `author-names.test.ts` fails when it and `SHADE_DTS` disagree.

The initializer plans all configuration changes before writing and installs synchronization hooks with explicit empty-tree support.

## For AI Agents

### Working in this directory

- **One IR, three backends, one walk.** Control flow is emitted once, in `core/emit.ts`; a
  backend supplies spelling and the divergent fragments (`core/backend.ts`). A new target
  implements `Backend`; it never forks the walk. A new divergent intrinsic is one entry in
  `core/intrinsics.ts`.
- **What an operation reads and writes is one table.** An analysis that walks an expression's
  operands asks `eachOperand` in `core/passes/access.ts`, and never tests a builtin's name for
  what it does with an argument (`arrayLength` measures its array and reads no element; an
  atomic's first argument is a place). Three analyses each learned `arrayLength` on their own,
  and the fourth, which had not, kept a correct loop off the GPU (#345). A new builtin that takes
  a pointer gets its row there, or `argument-access.test.ts` fails. A call that carries a
  `declRef` reaches a function the module declares, which wins over the builtin of its name
  (Rule 9.5), so the table is read through `callArgAccess`, never by the call's name alone.
- **The pre-emit pipeline is shared.** `lowerForBackend` runs `renamePredeclaredFunctions` (a
  function the module declares under a name its target predeclares becomes another, so from there
  a call's name says whether it reaches the declaration or the builtin, Rule 9.5), `validate`,
  `assertCaps`, `assertBuiltins`, then `autoVars`, `lowerModule`, O2's module-level
  `specializeCalls` (shared helpers for constant booleans and demanded return fields),
  O2's `restructureCalls` (producer/consumer fusion, including single-use local chains,
  local aggregate splitting and shared arithmetic helpers), O2's `storageLoadReuse`
  (scalar/vector storage caches within write-free regions and proven fixed loops),
  `fp64Lower`, `selectComposite`, the
  backend's own lowerings, its `optimize` at any tier, and `settleConstExprs`, which gives a
  constant expression the target would refuse to evaluate its value at run time (#368). Put a
  target-neutral rewrite there, not in a backend.
- **Mutability is a type split.** Produced values and `Var` are `Node` (has `.assign`); a `Let`,
  a parameter and a module constant are `ReadonlyNode`, so assigning one is a `tsc` error. The
  runtime is one class, so emit is unaffected. `autoVars` turns `const x = expr; x.assign(…)`
  into a real `var` on every backend.
- **DCE distinguishes stores from external reads.** Pure direct or compound stores to an
  unread scalar local can disappear with its declaration; the store's own self-read does not
  keep it alive. Aggregate places, for headers, other reads and effectful or opaque expressions
  remain conservative. The existing fixpoint cleans up exposed dependencies; `raw` functions
  are skipped.
- **GLSL driver workarounds stay in the backend.** Integer division/remainder helpers select a
  defined divisor before arithmetic. Final GLSL-only switch-continue lowering uses loop-local
  flags and guarded suffixes, preserving for headers and break targets; it skips `raw` functions.
- **WebGL shader objects are temporary.** `core/gl-compute.ts` deletes compiled shaders after
  linking, detaches them from successful programs, and deletes failed programs. Cached programs
  pass `isProgram` before reuse so a restored context recompiles invalidated entries.
- **Never unify a constant's two values.** `ConstDecl.wgslValue` is the shader literal,
  `cpuValue` the full-precision one the oracle uses. A vec / array / struct constant sets
  `valueExpr` instead (author it with `constExpr`), and it wins on every backend.
- **The oracle is an f64 algebra oracle.** It does not see f32 rounding (`core/passes/precision.ts`
  is the f32 mode). `raw` and un-swapped `placeholder` statements throw there.
- **`raw` statements are GPU-only and paired per target.** GLSL emits the `glsl` payload and
  throws `UnsupportedFeatureError` when it is missing. An un-swapped `placeholder` is a comment
  in WGSL and a throw in GLSL; run `composeModule` first.
- **`matchExpr` never reaches `emitExpr`.** `lowerModule` hoists it; a leak throws.
- **Source locations are a side table.** `core/diagnostics/loc.ts` keys a `WeakMap` by node
  identity, so emit is unchanged and tracing is off by default. Lowering rebuilds nodes, so call
  `getLoc` only on the authored module. Frame filtering normalizes Windows separators and
  decoded file URLs for comparison; the recorded location keeps the frame's source path.
- **Authoring surface changes follow `docs/language-design.md`.** A name an author can write
  comes from WGSL, ECMAScript or the §9 extension table; cite the rule in the pull request.
  A name added to or removed from the ambient library changes `__api__/author-names.md`:
  re-bake with `bun run bake:author-names`. An added name needs an accepted proposal that
  lists it under `names:` (`changes/README.md`).
- **Publishing.** `core/` stays private apart from `core/ir`. A new export changes
  `__api__/surface.md`: re-bake with `bun run bake:api-surface` and commit the diff.

### Testing requirements

- Tests are co-located (`*.test.ts` beside the file). Examples and their emit goldens
  (`examples/__emit-goldens__/`) are tested from `examples/`.

  oracle half for the chains.

- After writing shader source, `bun run format:semicolons`; before pushing, `bun run lint` and
  `bun run format:check`.

## Private kernel input layouts

`core/passes/kernel-project.ts` derives compact read-only scalar inputs from a lowered kernel
without modifying the authored module. `compiler/ts/host-face.ts` keeps both GPU variants and
logical parameter layouts. `core/host-kernel.ts` selects the full variant for resident or fused
calls. `core/host-entry.ts` runs the full logical pack through a private physical write map,
which preserves validation and getter order while omitting unused GPU bytes (change 0082).
